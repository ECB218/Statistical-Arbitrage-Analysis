# Statistical-Arbitrage-Analysis
This report tests a trading strategy on two chip companies, NVIDIA (NVDA)  and Broadcom (AVGO). It uses five years of daily share prices. The first three years were used to check whether the two share prices tend to move together. The last two years were used to see how the strategy would have performed on data it had not seen before.
